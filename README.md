# โปรแกรมจัดรูปแบบวิทยานิพนธ์ (Thesis Formatter)

เว็บแอปสำหรับนักเรียน/นักศึกษา — **วางข้อความบทที่ 1–5 ลงไป แล้วได้ไฟล์ Microsoft Word (.docx)
ที่จัดหน้า ฟอนต์ ขนาดตัวอักษร และย่อหน้าตามคู่มือการพิมพ์วิทยานิพนธ์ให้อัตโนมัติ**

ทำงานทั้งหมดในเบราว์เซอร์ ไม่ต้องติดตั้งอะไร ไม่ต้องมีเซิร์ฟเวอร์ ไม่ส่งข้อมูลออกไปที่ใด

---

## ปัญหาที่โปรแกรมนี้แก้

นักเรียนเขียนเนื้อหาได้ แต่ **จัดรูปแบบตามฟอร์มไม่ได้** — ขนาดตัวอักษรไม่ตรง ย่อหน้าไม่เท่ากัน
ระยะขอบผิด เลขหน้าไม่ถูกที่ หัวข้อไม่เป็นระบบ

โปรแกรมนี้รับหน้าที่ "จัดรูปแบบ" ทั้งหมด นักเรียนมีหน้าที่แค่ **เขียนเนื้อหาแล้วคัดลอกมาวาง**

---

## ความสามารถ

| ส่วน | ทำอะไรได้ |
|---|---|
| **บทที่ 1–5** | วางข้อความ → แยกชื่อบท หัวข้อหลัก หัวข้อรอง หัวข้อย่อย เนื้อความ รายการ อัตโนมัติ |
| **บรรณานุกรม** | จัดย่อหน้าแบบแขวน (hanging indent) และเรียงลำดับ ไทยก่อน–อังกฤษหลัง |
| **ภาคผนวก** | บรรทัด "ภาคผนวก ก/ข/ค" กลายเป็นหน้าคั่นกึ่งกลางอัตโนมัติ |
| **ส่วนหน้า** | ปกนอก ปกใน หน้าอนุมัติ บทคัดย่อไทย/อังกฤษ กิตติกรรมประกาศ สารบัญ สารบัญตาราง สารบัญภาพ |
| **ประวัติผู้วิจัย** | กรอกแบบฟอร์ม → ได้หน้าประวัติตามแบบ |
| **ตั้งค่ารูปแบบ** | ปรับได้ทุกค่า: ขอบกระดาษ ฟอนต์ ขนาด การเยื้อง ระยะบรรทัด ตำแหน่งเลขหน้า |
| **ส่งออกทั้งเล่ม** | รวมทุกส่วนเป็นไฟล์เดียว แยก section ให้เอง — ส่วนหน้าใช้เลขหน้า ก ข ค · เนื้อเรื่องเริ่มนับ 1 ใหม่ |

พร้อม **ตัวอย่างหน้ากระดาษ A4 แบบเรียลไทม์** และ **ตัวแก้โครงสร้าง** สำหรับกรณีที่โปรแกรมเดาประเภทบรรทัดผิด

---

## วิธีใช้

0. เลือก **รูปแบบ** ของสถาบันที่ช่องมุมขวาบน (ดูตารางด้านล่าง)
1. เลือกแท็บบทที่ต้องการ
2. คัดลอกข้อความของบทนั้นมาวางในช่องด้านซ้าย (จาก Word, PDF, Google Docs หรือพิมพ์เองก็ได้)
3. ดูตัวอย่างด้านขวา — ถ้าแยกประเภทบรรทัดผิด แก้ได้ที่ "โครงสร้างที่ตรวจพบ"
4. กด **ดาวน์โหลด .docx**

### เครื่องหมายกำกับ (ถ้าอยากคุมเอง)

| พิมพ์ | ได้ |
|---|---|
| `# หัวข้อ` | หัวข้อหลัก (18 พอยต์ ตัวหนา) |
| `## หัวข้อ` | หัวข้อรอง |
| `### หัวข้อ` | หัวข้อย่อย |
| `#### หัวข้อ` | หัวข้อย่อยระดับ 4 |
| `> ข้อความ` | ข้อความอ้างอิงยกมา (เยื้องเข้า) |
| `**ข้อความ**` | ตัวหนาภายในบรรทัด |

บรรทัดที่ขึ้นต้นด้วย `1.1` หรือ `1.1.1` จะกลายเป็นหัวข้อรอง/ย่อยให้เอง

## ชุดรูปแบบที่มีให้เลือก

เลือกได้จากช่อง **“รูปแบบ”** มุมขวาบน — สลับได้ตลอดเวลา ข้อความที่พิมพ์ไว้ไม่หาย
ค่าทุกตัวสกัดมาจากไฟล์ต้นแบบจริง ไม่ได้ประมาณเอง

| | **มสธ.** | **มหาวิทยาลัยชินวัตร** |
|---|---|---|
| ที่มา | คู่มือการพิมพ์วิทยานิพนธ์ มสธ. ฉบับปรับปรุง พ.ศ. 2546 | เทมเพลตพิมพ์วิทยานิพนธ์-งานวิจัย (APA 6th) |
| ฟอนต์ | AngsanaUPC | TH SarabunPSK |
| ขอบ บน/ล่าง | 3.81 / 2.54 ซม. | 2.54 / 2.54 ซม. |
| ขอบ ซ้าย/ขวา | 3.81 / 2.54 ซม. | 3.81 / 2.54 ซม. |
| “บทที่ X” · ชื่อบท | 20 · 22 พอยต์ | 18 · 18 พอยต์ |
| หัวข้อหลัก | 18 พอยต์ ตัวหนา | 16 พอยต์ ตัวหนา |
| เนื้อความ | 16 พอยต์ · เยื้องบรรทัดแรก 54 pt · ชิดขอบแบบไทย | 16 พอยต์ · เยื้องบรรทัดแรก 36 pt · ชิดซ้าย |
| บรรณานุกรม | ย่อหน้าแขวน 54 pt | ย่อหน้าแขวน 36 pt (APA) |
| เลขหน้า | กึ่งกลางหัวกระดาษ 16 พอยต์ | ชิดขวาหัวกระดาษ 14 พอยต์ |
| เลขหน้าส่วนหน้า | ก ข ค | i ii iii |
| ประวัติผู้เขียน | 6 ช่อง | 9 ช่อง (เพิ่มที่อยู่ โทรศัพท์ อีเมล ผลงาน) |

ทั้งสองชุดใช้กระดาษ A4 · ระยะบรรทัดเดี่ยว · ไม่แสดงเลขหน้าที่หน้าแรกของแต่ละบท ·
เนื้อเรื่องเริ่มนับหน้า 1 ใหม่

ถ้าสถาบันของคุณกำหนดต่างจากทั้งสองชุด **ปรับได้ทุกค่าในแท็บ "ตั้งค่ารูปแบบ"**
แล้วทุกเอกสารจะใช้ค่าใหม่ทันที

### เพิ่มชุดรูปแบบของสถาบันอื่น

แก้ไฟล์เดียว: [`js/templates.js`](js/templates.js) — คัดลอกบล็อก `SPEC_STOU` หรือ `SPEC_SIU`
เปลี่ยนค่าให้ตรงคู่มือของสถาบัน แล้วเพิ่มรายการใหม่ใน `PRESETS` และ `PRESET_ORDER`

## นำขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้เข้าไป (หรือ push ด้วย git)

   ```bash
   git init
   git add .
   git commit -m "เริ่มต้นโปรแกรมจัดรูปแบบวิทยานิพนธ์"
   git branch -M main
   git remote add origin https://github.com/<ชื่อผู้ใช้>/<ชื่อ-repo>.git
   git push -u origin main
   ```

3. ไปที่ **Settings → Pages** เลือก **Source: GitHub Actions**
   (ไฟล์ `.github/workflows/pages.yml` เตรียมไว้ให้แล้ว — จะ deploy อัตโนมัติทุกครั้งที่ push)

   หรือถ้าจะใช้แบบง่าย: เลือก **Source: Deploy from a branch → main → / (root)**

4. รอสักครู่ เว็บจะขึ้นที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

### รันในเครื่องเพื่อทดสอบ

```bash
python -m http.server 8777
```

แล้วเปิด <http://localhost:8777>

> เปิดไฟล์ `index.html` ตรง ๆ ก็ใช้ได้ (ไม่ได้ใช้ ES modules) แต่บางเบราว์เซอร์
> จำกัด `localStorage` บน `file://` ทำให้ไม่บันทึกงานอัตโนมัติ — แนะนำให้รันผ่านเซิร์ฟเวอร์

## โครงสร้างโค้ด

```
index.html            หน้าเว็บและแม่แบบ UI
css/style.css         สไตล์ส่วนติดต่อผู้ใช้ (รองรับโหมดสว่าง/มืด)
js/
  zip.js              ตัวสร้างไฟล์ ZIP (docx คือ ZIP) — เขียนเอง ไม่มี dependency
  templates.js        ข้อกำหนดรูปแบบ + หัวข้อมาตรฐานของแต่ละบท
  parser.js           แปลงข้อความดิบ -> โครงสร้างย่อหน้า
  docxgen.js          สร้าง OOXML (WordprocessingML) และประกอบเป็น .docx
  preview.js          แสดงตัวอย่างหน้ากระดาษ A4 + ประเมินเลขหน้า
  frontmatter.js      สร้างปก หน้าอนุมัติ บทคัดย่อ สารบัญ ประวัติผู้วิจัย
  app.js              ส่วนติดต่อผู้ใช้ สถานะ และการส่งออก
```

**ไม่มี dependency ภายนอกเลย** ไม่ต้อง `npm install` ไม่ต้อง build

## ข้อจำกัดที่ควรรู้

- ตัวอย่างด้านขวาเป็นการ **ประมาณ** การแบ่งหน้า (ตัดที่ระดับย่อหน้า) — เลขหน้าจริงให้ยึดตามที่ Word แสดง
- เลขหน้าในสารบัญแบบ static เป็นค่าประมาณ หากต้องการเลขหน้าที่ตรงเป๊ะ ให้เลือกโหมด
  "ใช้ฟิลด์สารบัญอัตโนมัติของ Word" แล้วกด <kbd>Ctrl</kbd>+<kbd>A</kbd> ตามด้วย <kbd>F9</kbd> ใน Word
- เครื่องที่เปิดไฟล์ต้องมีฟอนต์ที่เลือกไว้ (Windows ที่ติดตั้งภาษาไทยมี AngsanaUPC อยู่แล้ว)
- โปรแกรมช่วย **จัดรูปแบบ** เท่านั้น ไม่ได้ตรวจความถูกต้องทางวิชาการ ไม่ได้เขียนเนื้อหาให้
  และไม่ทดแทนการตรวจของอาจารย์ที่ปรึกษา
- ยังไม่รองรับการวางตาราง/รูปภาพโดยตรง (ให้ใส่ชื่อตาราง/ภาพไว้ แล้วไปแทรกของจริงใน Word)
