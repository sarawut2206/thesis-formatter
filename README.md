# โปรแกรมจัดรูปแบบรายงานโครงงาน

เว็บแอปสำหรับนักเรียนมัธยม — **วางข้อความบทที่ 1–5 ลงไป แล้วได้ไฟล์ Microsoft Word (.docx)
ที่จัดหน้า ฟอนต์ ขนาดตัวอักษร ย่อหน้า และตาราง ให้อัตโนมัติ**

ทำงานทั้งหมดในเบราว์เซอร์ ไม่ต้องติดตั้งอะไร ไม่ต้องมีเซิร์ฟเวอร์
งานของนักเรียนเก็บอยู่ในเครื่องตัวเอง ไม่ถูกส่งออกไปไหน — ยกเว้นเมื่อกดใช้ **ผู้ช่วย AI** ซึ่งจะส่งข้อความไปยังผู้ให้บริการ AI ที่ผู้ใช้เลือกเอง

---

## ปัญหาที่โปรแกรมนี้แก้

นักเรียนเขียนเนื้อหาโครงงานได้ แต่ **จัดรูปแบบตามฟอร์มไม่ได้** — ขนาดตัวอักษรไม่ตรง
ย่อหน้าไม่เท่ากัน ระยะขอบผิด เลขหน้าไม่ถูกที่ หัวข้อไม่เป็นระบบ ตารางเละ

โปรแกรมนี้รับหน้าที่ "จัดรูปแบบ" ทั้งหมด นักเรียนมีหน้าที่แค่ **เขียนเนื้อหาแล้วคัดลอกมาวาง**

---

## ความสามารถ

| ส่วน | ทำอะไรได้ |
|---|---|
| **บทที่ 1–5** | วางข้อความ → แยกชื่อบท หัวข้อหลัก หัวข้อย่อย เนื้อความ รายการ **และตาราง** อัตโนมัติ |
| **อัปโหลดไฟล์** | ดึงข้อความจากไฟล์ **PDF · Word (.docx) · .txt** เข้าช่องพิมพ์ได้เลย ไม่ต้องคัดลอกทีละหน้า |
| **ตาราง** | สร้างเป็นตาราง Word จริง มีเส้นขอบ หัวตารางซ้ำทุกหน้า ความกว้างคอลัมน์ปรับตามเนื้อหา |
| **บรรณานุกรม** | จัดย่อหน้าแบบแขวน (hanging indent) และเรียงลำดับ ไทยก่อน–อังกฤษหลัง |
| **ภาคผนวก** | บรรทัด "ภาคผนวก ก/ข/ค" กลายเป็นหน้าคั่นกึ่งกลางอัตโนมัติ |
| **ส่วนหน้า** | ปก · หน้ารับรองโครงงาน · บทคัดย่อ · กิตติกรรมประกาศ · สารบัญ · สารบัญตาราง · สารบัญภาพ |
| **ประวัติผู้จัดทำ** | รองรับหลายคน (โครงงานกลุ่ม) |
| **ผู้ช่วย AI** | อ่านบทที่ 1 แล้วร่างบทที่ 2–5 และบทคัดย่อให้ (ต้องใส่คีย์ AI ของตัวเอง) |
| **ตั้งค่ารูปแบบ** | ปรับได้ทุกค่า: ขอบกระดาษ ฟอนต์ ขนาด การเยื้อง ระยะบรรทัด ตำแหน่งเลขหน้า |
| **ส่งออกทั้งเล่ม** | รวมทุกส่วนเป็นไฟล์เดียว แยก section ให้เอง — ส่วนหน้าใช้เลขหน้า ก ข ค · เนื้อเรื่องเริ่มนับ 1 ใหม่ |

พร้อม **ตัวอย่างหน้ากระดาษ A4 แบบเรียลไทม์** และ **ตัวแก้โครงสร้าง** สำหรับกรณีที่โปรแกรมเดาประเภทบรรทัดผิด

## วิธีใช้

0. เลือก **รูปแบบ** ที่ช่องมุมขวาบน (ดูตารางด้านล่าง)
1. เลือกแท็บบทที่ต้องการ
2. ใส่ข้อความของบทนั้นในช่องด้านซ้าย ทำได้ 2 ทาง
   - คัดลอกมาวาง (จาก Word, PDF, Google Docs หรือพิมพ์เองก็ได้)
   - หรือกดปุ่ม **📄 อัปโหลดไฟล์** แล้วเลือกไฟล์ `.pdf` `.docx` `.txt`
3. ดูตัวอย่างด้านขวา — ถ้าแยกประเภทบรรทัดผิด แก้ได้ที่ "โครงสร้างที่ตรวจพบ"
4. กด **ดาวน์โหลด .docx**

### อัปโหลดไฟล์เข้ามาแทนการคัดลอก

ปุ่ม **📄 อัปโหลดไฟล์** อยู่เหนือช่องพิมพ์ของแต่ละบท รองรับ

| ชนิดไฟล์ | ความแม่นยำ | หมายเหตุ |
|---|---|---|
| **.docx (Word)** | **ตรงทุกตัวอักษร** | อ่านตารางออกมาเป็นตารางจริงครบทุกช่อง — **แนะนำให้ใช้แบบนี้** |
| **.pdf** | ตัวอักษรตรง แต่ตารางต้องตรวจทาน | ดูข้อจำกัดด้านล่าง |
| **.txt / .md** | ตรงทุกตัวอักษร | — |

โปรแกรมอ่านไฟล์ **ในเครื่องของนักเรียนเอง** ไม่มีการอัปโหลดขึ้นเซิร์ฟเวอร์ใด ๆ

**ทำไม PDF ถึงไม่แม่นเท่า .docx**
ไฟล์ PDF ไม่ได้เก็บว่า "ตรงนี้คือตาราง" เก็บแต่ว่าตัวอักษรแต่ละตัวอยู่พิกัดไหนบนหน้ากระดาษ
โปรแกรมจึงต้องเดาขอบคอลัมน์จากระยะห่าง ผลที่ได้คือ

- ตารางส่วนใหญ่ถูกต้อง แต่ **ช่องที่ข้อความยาวจนตกบรรทัด** อาจสลับช่องกันได้
- ข้อความปกติ (ไม่ใช่ตาราง) แม่นยำดี รวมทั้งสระอำ/สระอา ที่ Word มักส่งออกมาผิด

ถ้ามีไฟล์ `.docx` ต้นฉบับอยู่แล้ว **ให้ใช้ `.docx`** จะได้ผลตรงกว่าเสมอ
ถ้า PDF เป็นไฟล์ที่ได้จากการสแกนเป็นรูปภาพ จะดึงข้อความไม่ได้ ต้องแปลงด้วยโปรแกรม OCR ก่อน

### การใส่ตาราง

รองรับ 2 แบบที่นักเรียนใช้บ่อยที่สุด

**แบบที่ 1 — คั่นด้วยเครื่องหมาย `|`**

```
| ลำดับ | วัสดุและอุปกรณ์ | จำนวน | หน้าที่ |
|---|---|---|---|
| 1 | บอร์ด Arduino Uno | 1 บอร์ด | ประมวลผลและควบคุมระบบ |
| 2 | เซนเซอร์อินฟราเรด | 2 ตัว | ตรวจจับเท้า |
```

**แบบที่ 2 — คัดลอกตารางจาก Word หรือ Excel มาวางตรง ๆ**
(ช่องจะถูกคั่นด้วยแท็บโดยอัตโนมัติ)

บรรทัดแรกจะกลายเป็นหัวตาราง (ตัวหนา จัดกึ่งกลาง และซ้ำทุกหน้าถ้าตารางยาว)
ส่วนชื่อตาราง เช่น `ตารางที่ 3.1 วัสดุและอุปกรณ์` ให้พิมพ์ไว้บรรทัดก่อนหน้าตาราง

### เครื่องหมายกำกับอื่น ๆ

| พิมพ์ | ได้ |
|---|---|
| `# หัวข้อ` | หัวข้อหลัก |
| `## หัวข้อ` | หัวข้อระดับ 2 |
| `### หัวข้อ` | หัวข้อระดับ 3 |
| `> ข้อความ` | ข้อความอ้างอิงยกมา (เยื้องเข้า) |
| `**ข้อความ**` | ตัวหนาภายในบรรทัด |

บรรทัดที่ขึ้นต้นด้วย `1.1` หรือ `1.1.1` จะกลายเป็นหัวข้อระดับ 2/3 ให้เอง

## ผู้ช่วย AI (ไม่บังคับ)

เมื่อนักเรียนเขียน **บทที่ 1** เสร็จ กดปุ่ม **✨ ให้ AI ร่างบทนี้** ในบทที่ 2–5
หรือกด **ร่างบทที่ 2–5 ทั้งหมด** ในแท็บ *ผู้ช่วย AI* ได้เลย

### ต้องใส่คีย์ของตัวเอง

เว็บนี้เป็นไฟล์สแตติกล้วน ไม่มีเซิร์ฟเวอร์ จึงเรียก AI จากเบราว์เซอร์โดยตรง —
ผู้ใช้แต่ละคนต้องใส่คีย์ของตัวเองในแท็บ *ผู้ช่วย AI*

| ผู้ให้บริการ | ขอคีย์ | หมายเหตุ |
|---|---|---|
| **Google Gemini** | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) | **มีโควตาใช้ฟรี** — เหมาะกับโรงเรียน |
| Anthropic Claude | [console.anthropic.com](https://console.anthropic.com/settings/keys) | ภาษาไทยดีมาก แต่เสียเงิน |
| OpenAI | [platform.openai.com](https://platform.openai.com/api-keys) | เสียเงิน |

> ⚠️ **ห้ามใส่คีย์ลงในโค้ดแล้ว push ขึ้น GitHub** คีย์ที่หลุดสาธารณะจะถูกผู้อื่นนำไปใช้จนคุณต้องจ่ายเงิน
> โปรแกรมนี้เก็บคีย์ไว้ใน `localStorage` ของเบราว์เซอร์เครื่องนั้นเท่านั้น และ **ไม่ติดไปกับไฟล์ “บันทึกงาน” (.json)**
> แต่ใครก็ตามที่ใช้เครื่องเดียวกันจะเปิดดูคีย์ได้ — บนเครื่องสาธารณะให้กด **“ลบคีย์ออกจากเครื่อง”** เมื่อใช้เสร็จ

### สิ่งที่ AI จะไม่ทำให้ (โดยตั้งใจ)

- **ไม่แต่งผลการทดลอง** — เว้นเป็นวงเล็บ เช่น `(กรอกผลที่ได้จริง)` ให้นักเรียนเติม
- **ไม่แต่งบรรณานุกรม** — AI มักสร้างชื่อหนังสือและงานวิจัยที่ไม่มีอยู่จริง นักเรียนต้องค้นและพิมพ์เอง
- **ไม่เปลี่ยนหัวข้อโครงงาน** — ร่างต่อยอดจากบทที่ 1 เท่านั้น

ผลลัพธ์เป็นเพียง **ร่างแรก** — นักเรียนต้องอ่าน แก้ไข และเติมข้อมูลจริง
โดยมีครูที่ปรึกษาตรวจสอบทุกครั้ง โปรแกรมนี้ไม่ได้ทำโครงงานแทนนักเรียน

## ชุดรูปแบบที่มีให้เลือก

เลือกได้จากช่อง **“รูปแบบ”** มุมขวาบน — สลับได้ตลอดเวลา ข้อความที่พิมพ์ไว้ไม่หาย
ค่าทุกตัวสกัดมาจากไฟล์ต้นแบบเอกสารวิชาการจริง ไม่ได้ประมาณเอง

| | **แบบที่ 1** | **แบบที่ 2** |
|---|---|---|
| ตัวอักษร | AngsanaUPC | TH SarabunPSK |
| ขอบ บน/ล่าง | 3.81 / 2.54 ซม. | 2.54 / 2.54 ซม. |
| ขอบ ซ้าย/ขวา | 3.81 / 2.54 ซม. | 3.81 / 2.54 ซม. |
| “บทที่ X” · ชื่อบท | 20 · 22 พอยต์ | 18 · 18 พอยต์ |
| หัวข้อหลัก | 18 พอยต์ ตัวหนา | 16 พอยต์ ตัวหนา |
| เนื้อความ | 16 พอยต์ · เยื้องบรรทัดแรก 54 pt · ชิดขอบแบบไทย | 16 พอยต์ · เยื้องบรรทัดแรก 36 pt · ชิดซ้าย |
| บรรณานุกรม | ย่อหน้าแขวน 54 pt | ย่อหน้าแขวน 36 pt (APA) |
| ตาราง | 14 พอยต์ · เส้นขอบเดี่ยว · หัวตารางหนา กึ่งกลาง | เหมือนกัน |
| เลขหน้า | กึ่งกลางหัวกระดาษ 16 พอยต์ | ชิดขวาหัวกระดาษ 14 พอยต์ |
| เลขหน้าส่วนหน้า | ก ข ค | i ii iii |

ทั้งสองแบบใช้กระดาษ A4 · ระยะบรรทัดเดี่ยว · ไม่แสดงเลขหน้าที่หน้าแรกของแต่ละบท ·
เนื้อเรื่องเริ่มนับหน้า 1 ใหม่

ถ้าโรงเรียนกำหนดต่างจากทั้งสองแบบ **ปรับได้ทุกค่าในแท็บ "ตั้งค่ารูปแบบ"**
แล้วทุกเอกสารจะใช้ค่าใหม่ทันที

### เพิ่มชุดรูปแบบของโรงเรียนอื่น

แก้ไฟล์เดียว: [`js/templates.js`](js/templates.js) — คัดลอกบล็อก `SPEC_ANGSANA` หรือ `SPEC_SARABUN`
เปลี่ยนค่าให้ตรงคู่มือของโรงเรียน แล้วเพิ่มรายการใหม่ใน `PRESETS` และ `PRESET_ORDER`

## นำขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้

   ```bash
   git init && git add . && git commit -m "เริ่มต้นโปรแกรมจัดรูปแบบรายงานโครงงาน" && git branch -M main && git remote add origin https://github.com/<ชื่อผู้ใช้>/<ชื่อ-repo>.git && git push -u origin main
   ```

2. ไปที่ **Settings → Pages** เลือก **Source: GitHub Actions**
   (ไฟล์ `.github/workflows/pages.yml` เตรียมไว้ให้แล้ว จะ deploy อัตโนมัติทุกครั้งที่ push)
   หรือแบบง่าย: เลือก **Deploy from a branch → main → / (root)**

3. เว็บจะขึ้นที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

### รันในเครื่องเพื่อทดสอบ

```bash
python -m http.server 8777
```

แล้วเปิด <http://localhost:8777>

## โครงสร้างโค้ด

```
index.html            หน้าเว็บและแม่แบบ UI
css/style.css         สไตล์ส่วนติดต่อผู้ใช้ (รองรับโหมดสว่าง/มืด)
js/
  zip.js              ตัวสร้างไฟล์ ZIP (docx คือ ZIP) — เขียนเอง ไม่มี dependency
  templates.js        ข้อกำหนดรูปแบบ + หัวข้อมาตรฐานของแต่ละบท
  parser.js           แปลงข้อความดิบ -> โครงสร้างย่อหน้าและตาราง
  docxgen.js          สร้าง OOXML (WordprocessingML) รวมถึงตาราง แล้วประกอบเป็น .docx
  preview.js          แสดงตัวอย่างหน้ากระดาษ A4 + ประเมินเลขหน้า
  frontmatter.js      สร้างปก หน้ารับรอง บทคัดย่อ สารบัญ ประวัติผู้จัดทำ
  importer.js         อ่านข้อความจากไฟล์ PDF / .docx / .txt — เขียนเอง ไม่มี dependency
  ai.js               ผู้ช่วย AI (เรียก Gemini / Claude / OpenAI ด้วยคีย์ของผู้ใช้เอง)
  app.js              ส่วนติดต่อผู้ใช้ สถานะ และการส่งออก
```

**ไม่มี dependency ภายนอกเลย** ไม่ต้อง `npm install` ไม่ต้อง build

## ข้อจำกัดที่ควรรู้

- ตัวอย่างด้านขวาเป็นการ **ประมาณ** การแบ่งหน้า (ตัดที่ระดับย่อหน้า) — เลขหน้าจริงให้ยึดตามที่ Word แสดง
- เลขหน้าในสารบัญเป็นค่าประมาณ หากต้องการเลขหน้าที่ตรงเป๊ะ ให้เลือกโหมด
  "ใช้ฟิลด์สารบัญอัตโนมัติของ Word" แล้วกด <kbd>Ctrl</kbd>+<kbd>A</kbd> ตามด้วย <kbd>F9</kbd> ใน Word
- ตารางที่มีการ **ผสานช่อง (merge cell)** ยังไม่รองรับ — ต้องไปผสานเองใน Word
- **นำเข้าจาก PDF**: ตารางที่มีช่องข้อความยาวจนตกบรรทัดอาจสลับช่อง ให้ตรวจทานก่อนใช้
  (ถ้ามีไฟล์ `.docx` ให้ใช้ `.docx` จะตรงทุกตัวอักษร) และ PDF ที่สแกนเป็นรูปภาพจะดึงข้อความไม่ได้
- ยังไม่รองรับการวาง **รูปภาพ** โดยตรง (ให้ใส่ชื่อภาพไว้ แล้วแทรกรูปจริงใน Word)
- เครื่องที่เปิดไฟล์ต้องมีฟอนต์ที่เลือกไว้ (Windows ที่ติดตั้งภาษาไทยมี AngsanaUPC อยู่แล้ว)
- โปรแกรมช่วย **จัดรูปแบบ** เท่านั้น ไม่ได้ตรวจความถูกต้องของเนื้อหา ไม่ได้เขียนให้
  และไม่ทดแทนการตรวจของคุณครูที่ปรึกษา
